# Window Cut mobile assets

The three files in this directory are byte-for-byte copies of the approved Agari brand assets in `brand/` at commit `03b30abb`. The native `AgariMark` component uses their exact 220 × 220 paths, with theme-aware window ink as described by the source brand README.

`../images/icon.png` is the approved app icon flattened onto its dark tile for the iOS opaque-icon requirement. The Android adaptive foreground and monochrome images and the splash image are centered renderings of the approved inverse mark; the adaptive background is the approved tile color `#171714`. Keep these derivatives in sync when the source mark changes.
