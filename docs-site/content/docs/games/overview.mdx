<AppLink href="/games">Games</AppLink> has seven modes: Practice, Duel, Lucky, Range, Moonshot, Line Rider and Candle Hop. They share Agari's live Windows, but have different scoring and money rules. A particular round still needs its own current game state, liquidity or participants.

Start with [Practice and arcade](/games/practice-and-arcade) to play without a stake. [Duel and Lucky](/games/duel-and-lucky) involve real devnet orders. [Range and Moonshot](/trading/range-and-moonshot) use a separate prefunded reserve. Read the entry cost and result rule in each mode before signing; money-backed games use **devnet test tUSDC** and are separate from the [desk](/agents/desk).

The [ordinary call guide](/trading/first-trade) explains the Window beneath the games. Use <AppLink href="/status">Status</AppLink> if a round is not listing or settling.
