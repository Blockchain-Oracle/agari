<AppLink href="/proof">Proof</AppLink> lists settled Windows. Start with a ticker or filter by source, then open a row. The page shows the **opening** and **closing** boundary values, their recording transactions and the policy used to accept them. The program settles from these recorded values, not the latest display price.

<GuideCapture name="proofFeed" caption="The connected-session proof feed is public data. Its rows show closed Windows and their policy sources." />

## Check the units and source

Equity and individual PreStocks token prints are prices; a basket print is an **index in points**. In this AI Labs example, the PreStocks catalogue supplied both members in one read and **Agari's attestor** signed the calculated index. That is different from a Pyth-signed update.

<GuideCapture name="basketProof" caption="The AI Labs detail names its PreStocks source, index points and recording transactions. A recording link is evidence of an instruction; verify the transaction's actual effect if you need to audit it." />

Use the [price-source map](/architecture/price-sources) to see each verification path. An absent archived source package should be treated as unavailable evidence even if the on-chain print and recording transaction are present.
