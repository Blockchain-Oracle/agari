# S21 — The desk: an agent holds a basket of PreStocks for you, inside limits the program enforces

**Goal:** Shijima (the user's `open-serv` project, Robinhood Chain) moved to Solana + PreStocks + Jupiter. You decide **what** to own (a basket preset + cash sleeve + limits); the desk decides only **when**; the program enforces the money limits; every decision, including "nothing to do", is written down and fingerprinted on-chain in the same transaction as the trade. Approved by the user on 2026-09-22 (plan `~/.claude/plans/quizzical-booping-ocean.md` §§4–5 for the UX, §8 for the engineering). The earlier rule "agents do not trade real tokens" is withdrawn by the user.

- **Where it runs:** the desk program and live desks are on **Solana mainnet** (PreStocks tokens exist only there). **Practice desks are paper ledgers with no transaction** (anyone, including judges and U.S. visitors). Everything is rehearsed on a **Surfpool mainnet fork** (`surfpool 1.5.0`) before one real lamport is spent; the real deploy (≈ 2.7–3.2 SOL rent) and the user's own desk ($50–100 USDC) are his spend at C7.
- **Token facts (mainnet, 2026-09-22):** Token-2022, 9 dp, **100 bps transfer fee** on every transfer, permanent delegate, freeze authority, pausable, `defaultAccountState: initialized` (a PDA can hold), ScaledUiAmount (OPENAI × 1.4861347; catalogue prices are per UI unit, chain and Jupiter are raw).
- **Jupiter:** CPI is Jupiter's recommended path (program `JUP6LkbZbjS1jKKwapdHNy74zcZ3tLUZoi5QNyVTaV4`); `/quote` + `/swap-instructions` with the desk PDA as the user; no IDL needed (opaque bytes, `address =` check). Lite-api is keyless (0.5 RPS); `JUPITER_API_KEY` for production.
- **Words (plan §5.1):** desk, mandate, basket, check, decision, record, practice; "above its mark" for the premium. The copy-trading strings "You're on the desk" / "Your desk balance" / "01 · The desk" are renamed so "desk" means one thing.
