# S18 — Always-on markets, pre-open calls, asset identity, editorial lift

**Goal:** Agari never looks empty and feels like a product, not a demo. Approved by the user on 2026-09-15 (plan r2, `~/.claude/plans/valiant-wibbling-kahan.md`).
1. **Always-on markets:** when NYSE is closed, `/markets` still shows every asset's last price and change, a real price chart of the last session, the session state with a countdown, what lists next per lane, and a next action. The marquee never says `LOADING` when a last price exists. Portfolio's empty state never dead-ends.
2. **Pre-open calls ("schedule a trade"):** on a Window listed before the open, a user rests a post-only call at their price; it fills within the first minute after the bell if the book comes to them, else the stake returns. Their wallet signs; nothing server-side holds keys.
3. **Asset identity:** real stock marks (inline SVG in Masayume's grammar) everywhere an asset appears, including the marquee, ticker hub, Sensei cards, portfolio rows and share cards.
4. **Editorial lift:** `/news`, the activity wire and the take card are redesigned from 2–3 generated 21st directions, one chosen and recorded, in Masayume's tokens.
5. **Cleanup:** the `21st review` errors, duplicated closed-market copy, leftover identity strings, and honest states for the deferred stages.

- **Token lanes deadlocked by a Switchboard outage (09-16, diagnosed 14:20–14:40Z).** Switchboard's gateway has returned `Gateway.fetchSignaturesConsensus failed (status 500, ERR_BAD_RESPONSE)` since **05:50:16Z**; a read-only probe of `fetchTokenQuote` from this machine still got 500 in 3.3 s at 14:36Z, for one symbol and for all four. `QUOTE_FAILURES_TO_HALT = 3`, so each xStock issuer was flagged `quote-unavailable` at 05:50:59Z after `confirmPasses = 2` matching observations, and all 12 token lanes paused.
- **The halt cannot self-heal.** Clearing needs `tokenHaltReason` to return null, which needs the streak under 3, which only `recordQuoteResult(..., true)` does. That is called solely by the relay's Switchboard pass, and only for a **due print slot on a live token Window** — which the roller will not open while the lane is halted. With every token Window expired by 11:51Z there are no due slots, so no quote is attempted, so the streak never resets: the lane stays paused even after the upstream recovers. The only reset is an ops restart (the streaks are in-process). 529 min halted as of 14:39Z, 0 token Windows open.
- **Do not restart ops during the outage.** A restart zeroes the streak, the roller opens token Windows, the relay's first quotes fail, and those Windows void on missing prints within minutes while burning roller float. The restart belongs *after* Switchboard recovers. See D-099.
- **Settlement was never wrong, only absent.** The stalled Windows voided honestly: `void NVDAx-5m #80 …: no open print by …` with signatures, the missing-print void. Index totals: token lanes **09-16 54 resolved / 302 voided**, 09-15 33 / 95; Regular lanes today **150 resolved / 2 voided**. So the token lane has been print-starved well beyond this outage, which the S6 evidence should say plainly.
- **The Jupiter timeouts are a separate, cosmetic fault** (my 13:14Z note wrongly blamed them for the halt). `xstock-spot` polls Jupiter Price v3 every 5 s with a 5 s abort on the **keyless** lite endpoint rated 0.5 RPS — about ten times its allowance — and its own header says it "never settles anything": it feeds the chart, the token maker's reference and the opt-in attested fallback. A direct probe answered 200 in ~1.0–1.3 s. Fix is `JUPITER_API_KEY` or a slower poll.

- Two root causes of "empty": every `/markets` surface keys off live Windows, and `/prices/latest` drops quotes older than 60 s. Masayume (24/7 crypto) never had a closed state.
- `print_archive` already holds a signed 5-minute intraday series per ticker per session with no read path; RedStone rows are keyed by ticker.
- The only pre-open refusal is `matching/place.rs:60-62`; PostOnly can never fill (`Walk::CrossCheck`); `min_rest_slots` never blocks a user's cancel; the roller already sweeps at lock; redeem folds `locked_cash` + bond.
