A Window never settles on "the latest price." Every print is a signed value checked on-chain at an exact timestamp — the first valid print for that boundary wins, and the check happens in the `agari-events` program itself, not off-chain.

| Ticker | Primary source today | What happens after the Pyth trial (≈ 2026-09-27) |
| --- | --- | --- |
| TSLA | Pyth, cross-checked against RedStone | Switches to RedStone-primary — registered in advance as a second policy version, no redeploy needed |
| QQQ, VOO | Pyth | Pause with an honest "no signed source" state, unless a source like Stork is added later |
| NVDA, AAPL, MSFT, META, AMZN, GOOGL | RedStone | Unchanged |
| The 24/7 token lane | Switchboard On-Demand | Unchanged |

## How each source is verified

- **Pyth** — a pull oracle update, verified against Wormhole's guardian set on-chain. Checked for the right feed id and that its timestamp lands within the Window boundary's allowed window.
- **RedStone** — a public gateway of signed data packages, no API key needed. The program requires at least 3 of 5 configured signers to agree, and for the first 5 minutes after the boundary it requires all 5 — an anti-selection rule, so a poster can't cherry-pick a favorable 3-of-5 subset while an honest relay can always post all 5.
- **Switchboard On-Demand** — the 24/7 token lane only. At least 3 distinct oracle signatures from one pinned queue, within a short admission window after the timestamp.

## The TSLA cross-check

TSLA additionally requires its RedStone check price to agree with its Pyth primary price within a divergence threshold. If they disagree beyond it, the Window voids with reason `CrossCheckDivergence` instead of settling on a guess — see [halts and voids](/trading/halts-and-voids).

## If no source covers a Window

A Series' price policy is a set of versions, each valid for a date range, registered in advance. If no version covers a Window's two boundaries, the Window simply isn't listed — the lane shows an honest "paused: no signed source" state rather than trading on an unverified number.
