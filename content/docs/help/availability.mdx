These guides describe the current implementation, not an aspiration. A route can exist in the app while its deployment is missing a program, a key, a service or funds. Read the page's live state and <AppLink href="/status">Status</AppLink> alongside any guide.

Agari runs on **Solana devnet** with **tUSDC** test collateral. A local screen or sample receipt is not proof that a corresponding live transaction settled — check the transaction itself.

## Supported paths and their prerequisites

| Feature | What it needs |
| --- | --- |
| Market browsing | A readable Window list, order book and price feed — no wallet. |
| A wallet order | A connected Wallet Standard wallet on Solana devnet, devnet SOL for fees, tUSDC, a live Window and an executable quote. |
| Portfolio and claims | The correct connected wallet and a settled or voided Window to claim from. |
| Trading Balance / tap-trading | `agari-vault` deployed and a funded, valid grant/session key. As of this snapshot, `agari-vault`'s deploy is a pending devnet sequence — check [Programs](/architecture/programs) for its current status before assuming tap-trading is live. |
| Pre-open ("schedule a call") | A Window listed before the open (the roller pre-lists the next session's first Window at the prior close) and a PostOnly order. |
| Sensei | An `AI_MODEL` setting and a matching provider credential, server-side. Without one, the dock still renders but says the reply is unavailable. |
| Reels / Takes | A wallet signature (no network fee) and the social store running. |
| The Room | A real position on that Window or ticker, read from the index. |
| Price alerts | An open browser tab watching a fresh, in-session price tick. |
| News | A readable headline feed — no wallet. |

## Deferred past the hackathon deadline

Cut for the 2026-09-18 deadline: **Earn** (the maker vault as a public supply-side reserve), **Range, Boost, Parlay and Private** (the specialist ticket types), **agents and copy trading**, **trade-from-X**, and **the games programs** (Practice, Duel, Lucky Draw, Line Rider, Candle Hop, Moonshot). Their app routes exist and render an honest "not live" state rather than a half-built flow — see the [games](/games/overview), [agents](/agents/overview) and [builders](/builders/overview) notes, and [trading's coming-soon page](/trading/coming-soon) for the specialist ticket types.

## Labels that need context

- **A void** ("no signed price arrived" or "the two price sources disagreed") returns your stake as credit. It is not a loss and not shown as a win.
- **A pre-open call resting** means your order is on the book waiting for the bell, not that it has filled.
- **"Signed price stale"** on a halted-looking ticker usually means no fresh print has arrived within the admission window, not that the market itself is broken.
