This page is a **23 September 2026 source review**, not a promise that a particular Window, game or quote is live every minute. Read <AppLink href="/status">Status</AppLink> and the screen's current state before signing.

The regular equity, Gap, 24/7 token, PreStocks and basket lanes have distinct clocks and [price sources](/architecture/price-sources). If a source is unavailable, the venue should pause the affected lane or void a Window whose required print does not arrive. A stopped lane is not a confirmed loss. A signature approval is not itself proof that a financial transaction landed; inspect the transaction before retrying.
