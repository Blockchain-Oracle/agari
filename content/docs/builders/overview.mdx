The Agari application is a separate repository from this documentation site. The current app branch reviewed for these guides is `integration/w1` at `c412501` (23 September 2026); `main` was 820 commits behind it at this check. The public app is at <AppLink href="/markets">useagari.xyz</AppLink>, but the GitHub repository is private.

Use [Local setup](/builders/local-setup) for the actual commands, [Source map](/builders/source-map) to locate each system, [Programs](/architecture/programs) for network-specific deployments, and [Price sources](/architecture/price-sources) for the oracle and attestation paths. The devnet acceptance ledger and the S21 desk rehearsal are different kinds of evidence; a local test does not prove a mainnet deploy.
